Authentication Process:
1. User registers
Username, email, password

2. FastAPI hashes the password
Store the hash in your Neon users table, not the plain password

3. User logs in
Find the user in Neon and verify their password

4. FastAPI creates a JWT
Return an access token if login succeeds

5. User requests their todos
Send the token; FastAPI verifies it and identifies the user

6. Return only that user's todos
Use the authenticated user's ID to query Neon
